# Pinned GitHub CLI writer evidence

The secret writer uses the official GitHub CLI release v2.103.0, source commit [7948e8056e45ac3c729b829e0eafe2d0797a95c6](https://github.com/cli/cli/commit/7948e8056e45ac3c729b829e0eafe2d0797a95c6). The workflow downloads the Linux AMD64 release asset and verifies its SHA-256 before making its absolute path available to the job:

- Asset: gh_2.103.0_linux_amd64.tar.gz
- Release asset URL: https://github.com/cli/cli/releases/download/v2.103.0/gh_2.103.0_linux_amd64.tar.gz
- SHA-256: fdd768eb70f6409f80fcfa9f3a1c0adf0fc98d827ab3ce0bed2ac22762c5d786
- The digest matches both the GitHub release API asset metadata and the release's gh_2.103.0_checksums.txt file. Publicly fetched source and release metadata bytes, with their hashes, are recorded in the private author evidence.

In that exact source commit, [http.go lines 67-72](https://github.com/cli/cli/blob/7948e8056e45ac3c729b829e0eafe2d0797a95c6/pkg/cmd/secret/set/http.go#L67-L72) retrieves the environment public key using safeurl.JoinPath, and [lines 130-139](https://github.com/cli/cli/blob/7948e8056e45ac3c729b829e0eafe2d0797a95c6/pkg/cmd/secret/set/http.go#L130-L139) sends the encrypted value with KeyID: pk.ID to the environment secret endpoint. PubKey.ID is decoded from response field key_id at [http.go lines 29-32](https://github.com/cli/cli/blob/7948e8056e45ac3c729b829e0eafe2d0797a95c6/pkg/cmd/secret/set/http.go#L29-L32); SecretPayload serializes it back as key_id at [lines 15-20](https://github.com/cli/cli/blob/7948e8056e45ac3c729b829e0eafe2d0797a95c6/pkg/cmd/secret/set/http.go#L15-L20). [set.go lines 335-353](https://github.com/cli/cli/blob/7948e8056e45ac3c729b829e0eafe2d0797a95c6/pkg/cmd/secret/set/set.go#L335-L353) decodes the returned public key, seals the plaintext using box.SealAnonymous, and Base64-encodes the ciphertext.

The escaping behavior is implemented in [safeurl.go lines 131-144](https://github.com/cli/cli/blob/7948e8056e45ac3c729b829e0eafe2d0797a95c6/internal/safeurl/safeurl.go#L131-L144): each supplied path component is passed through Go's url.PathEscape, then components are joined with literal slash separators. The same commit's [safeurl_test.go lines 134-139](https://github.com/cli/cli/blob/7948e8056e45ac3c729b829e0eafe2d0797a95c6/internal/safeurl/safeurl_test.go#L134-L139) asserts that "bar baz" becomes bar%20baz and "a/b" becomes a%2Fb. Therefore the fixed environment name glistening-friendship / demo, passed as one environment path component by getEnvPubKey and putEnvSecret, becomes glistening-friendship%20%2F%20demo in both routes. This resolves the encoding gap identified for the previously unpinned runner CLI.

The preflight job and both secret-bearing jobs obtain and checksum-verify the same immutable release asset. Each installation step checks the binary version. The writer independently executes the pinned absolute binary with --version in a stripped credential-free child before starting the write process; a mismatch or failed check stops with a fixed error code before secret stdin is supplied. The write process receives the existing secret value only through stdin and receives GH_TOKEN through its allowlisted environment.
