## Implementation

1. Separate the immutable finite transport ceiling from optional selection.
   Default worker asks source reader for deferred optional evidence. The reader
   verifies complete before/after changed source, pinned inventories, required
   contract/plan/validation and mandatory canonical recovery extras BEFORE a
   genuine qualification/probe. All optional omission names are reserved in the
   minimal packet from the beginning.
2. Source reader returns a detached immutable required snapshot and completion
   closure. A direct reader without a qualified profile retains a conservative
   700KiB optional-only budget; required data is never truncated to reach it.
3. Shared normal/recovery preparation first measures actual prompt+schema with
   the observed profile. The pure budget helper adds ONLY the exact remaining
   allowance to minimal serialized packet bytes. Prefix, schema, native65536
   margin and observed output allowance are counted once, not approximated.
4. Completion tries optional reports under the exact prospective serialized JSON
   size, including UTF-8/control escaping and removal of their omission name.
   Oversized/over-count/over-budget optional reports stay explicitly omitted.
   Selected text is still Git-blob verified and frozen-digest checked when present.
5. Before claim, shared preparation rejects any changed immutable projection,
   required text replacement, unknown evidence, invalid omission bookkeeping,
   >64KiB optional entry, >24 total entries or budget overflow, then prepares the
   final actual input again. Source/feedback/identity/plan/history/inventory and
   tracked-path snapshots are not replaced by completion output. Normal native
   claim and explicit existing-round recovery consume the same preparation path.
