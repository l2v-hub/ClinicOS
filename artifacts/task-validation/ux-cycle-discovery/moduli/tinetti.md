# Scala di Tinetti (POMA) — trascrizione del modulo cartaceo

Source: `Moduli/scala_tinetti_260818_125856.pdf` (2 pagine A4). Testo trascritto alla lettera. Stesso template grafico del Barthel.

## Layout

- **Banda di testata** blu navy scuro, testo bianco:
  - Titolo: **SCALA DI TINETTI**
  - Sottotitolo: `Performance-Oriented Mobility Assessment (POMA) - Valutazione di Equilibrio e Andatura`
- **Riquadro anagrafica**: `Paziente:` — a destra `Data Valut.:`; riga 2 `Data Nascita:`. Nessun operatore/reparto in testata.
- **Barra di sezione** blu medio per ciascuna delle due parti.
- **Tabella** 5 colonne: `#` | `Parametro` | `Descrizione e Criteri di Valutazione` | `Punti` | `Sel.`; una riga per opzione, `#`/`Parametro` in rowspan, eventuale specifica del parametro in corsivo piccolo sotto il nome, `Sel.` = checkbox. L'intestazione tabella si ripete a pagina 2.
- Piè di pagina `Pagina 1 di 2` / `Pagina 2 di 2`. **Una sola somministrazione per foglio.**

## 2. VALUTAZIONE DELL'ANDATURA (Max 12 Punti)

Nota corsiva sotto la barra: _Paziente cammina lungo un corridoio (circa 3 metri) a passo normale e poi rapido. Uso di ausili consentito._

| #   | Parametro                           | Descrizione e Criteri di Valutazione                                    | Punti |
| --- | ----------------------------------- | ----------------------------------------------------------------------- | ----- |
| 10  | Inizio della deambulazione          | Esitazione o più tentativi per partire                                  | 0     |
|     |                                     | Nessuna esitazione                                                      | 1     |
| 11  | Lunghezza e altezza del passo       | Piede DX non supera il SX durante la fase di volo                       | 0     |
|     |                                     | Piede DX supera il SX; il piede DX non si stacca completamente da terra | 1     |
|     |                                     | Piede SX non supera il DX durante la fase di volo                       | 0     |
|     |                                     | Piede SX supera il DX e si stacca completamente da terra                | 1     |
| 12  | Simmetria del passo                 | Passo DX e SX non appaiono di lunghezza uguale                          | 0     |
|     |                                     | Passo DX e SX appaiono di lunghezza uguale                              | 1     |
| 13  | Continuità del passo                | Interruzione o discontinuità tra i passi                                | 0     |
|     |                                     | I passi appaiono continui                                               | 1     |
| 14  | Traiettoria _(Valutata su 3 metri)_ | Marcata deviazione dalla linea retta                                    | 0     |
|     |                                     | Lieve/moderata deviazione o usa ausilio per mantenere la rotta          | 1     |
|     |                                     | Traiettoria dritta senza ausili                                         | 2     |
| 15  | Tronco                              | Marcata oscillazione o uso di ausili                                    | 0     |
|     |                                     | Flessione delle ginocchia o del tronco o allargamento delle braccia     | 1     |
|     |                                     | Nessuna oscillazione, tronco eretto, braccia coordinate                 | 2     |
| 16  | Base di appoggio                    | Talloni separati durante la deambulazione                               | 0     |
|     |                                     | Talloni quasi si toccano durante la deambulazione                       | 1     |

(Nella pagina 2 il nome «Inizio della deambulazione» compare in testa, perché l'item 10 è spezzato tra le due pagine.)

**Incongruenza di punteggio:** come stampato, l'item 11 offre una scelta 0/1 per il DX e una 0/1 per il SX ⇒ max 2; andatura = 1+2+1+1+2+2+1 = **10**, non 12 come dichiarato (totale 26, non 28). Il Tinetti originale prevede 4 sotto-voci (lunghezza DX, altezza DX, lunghezza SX, altezza SX), ciascuna 0/1. Inoltre la riga DX «supera il SX; il piede DX **non** si stacca completamente da terra = 1» mescola lunghezza (riuscita) e altezza (fallita), mentre la riga SX «supera il DX **e** si stacca completamente = 1» le combina entrambe riuscite.
