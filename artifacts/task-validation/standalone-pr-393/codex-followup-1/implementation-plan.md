## F2: do not confuse admission, grant expiry and live-session enforcement

- `expires_after` restricts issuance/reuse of the client secret, not duration of an established session.
- A backend Map released in negotiation finally guards in-flight requests only, not one live session.
- A timer that deletes an operator lease permits another session while the old provider session may still run.
- A browser watchdog or VAD remains bypassable by a modified client.
