== network requests during load and navigation
Session as Operatore (login → Turno → Pazienti → first patient → back → Terapia → Parametri → Consegne → Agenda → Farmaci → Turno → Pazienti), 2.5 s settle per step, backend on localhost:3001.

PRODUCTION BUNDLE (frontend/dist replayed under the dev origin by Playwright, config chunk pointed at :3001 in flight; no StrictMode): 90 API requests, 53 distinct URLs, 229,060 B of JSON, 89 CORS preflights.
Per step (requests / bytes): login screen 1 / 94 B; login→Turno 18 / 78.7 kB; Pazienti 15 / 17.9 kB; open patient 15 / 20.2 kB; back 3 / 13.5 kB; Terapia 9 / 11.4 kB; Parametri 3 / 9.1 kB; Consegne 4 / 13.3 kB; Agenda 2 / 11.1 kB; Farmaci 0; Turno again 5 / 35.8 kB; Pazienti again 15 / 17.9 kB.

Latency: no slow endpoint locally. Worst observed: /patients/:id/intake-review 78 ms, /patients/diary-unread 67 ms, /patients/page 59 ms, /therapy-slots 50 ms. Railway latency could not be measured from here.

Idle polling (95 s per page): Turno 11 requests / 64.7 kB (every 30 s: diary-unread-count + 2x diary-unread 7.2 kB; every 60 s: 2x therapy-slots 10.7 kB), about 420 requests and 2.4 MB per hour.
