# Phase 6 — Failure Mode Matrix

What happens when each dependency or step fails. Rule: **fail closed** (deny / no write / clear
error), **no silent fallback to a different provider**, **text path survives voice failures**,
**never a false success**.

policy applies when no policy version is active; unassigned identities fall back to legacy roles.
